#  Fresh Bite – Smart Cooking & Nutrition Assistant

##  Project Overview

Fresh Bite is a smart cooking and nutrition assistant designed to make healthy eating easier, more flexible, and accessible.

The application helps users discover recipes based on the ingredients they have, track calories and nutrition, find healthier ingredient alternatives, and learn basic cooking skills.

This project was developed using a user-centered design approach based on questionnaires, interviews, user needs, insights, and prototyping.

##  Project Goal

The main goal of Fresh Bite is to help users overcome common challenges when preparing healthy meals, including:

- Finding suitable healthy recipes
- Finding alternatives for unavailable ingredients
- Finding safe ingredient substitutions
- Calculating calories and nutritional values
- Planning meals based on available ingredients
- Learning how to prepare healthy meals
- Maintaining variety in meals

##  Target Users

Fresh Bite is designed for:

- People following a healthy lifestyle
- Beginner cooks
- People with dietary restrictions or allergies
- Fitness enthusiasts and athletes
- Home cooks
- People interested in exploring healthy recipes

##  User Research

The project included user research through:

- Online questionnaires
- User interviews
- Data analysis and visualization
- User needs analysis
- User insights analysis

The research showed that users commonly struggle with calculating nutritional values, finding suitable recipes, and finding appropriate ingredient substitutions.

##  Key Features

###  Cooking 101

A beginner-friendly cooking section that provides:

- Step-by-step cooking guidance
- Easy recipes
- Meal preparation tips
- Recipe suggestions based on available ingredients
- Custom recipe creation

###  AltEats

An ingredient substitution feature that helps users find suitable alternatives based on their dietary needs or available ingredients.

Users can search for ingredients and browse different alternative options.

###  Track Your Cal

A calorie and nutrition tracking feature that allows users to:

- Add meals
- Search for recipes
- Add custom meals
- Calculate total calories
- View calorie details
- Receive motivational feedback and tips

###  Recipe Suggestions

Users can receive recipe suggestions based on the ingredients they have available and their meal preferences.

###  User Profile

Users can manage their profile, edit their information, submit feedback, and rate recipes.

##  Design Process

The project followed a Human-Computer Interaction design process:

1. User Research
2. Interviews and Questionnaires
3. Data Analysis
4. Identifying User Needs
5. Identifying User Insights
6. Defining User Tasks
7. Low-Fidelity Prototyping
8. High-Fidelity Prototyping

##  Prototypes

The project includes both low-fidelity and high-fidelity prototypes.

The high-fidelity prototype includes the main user flows for:

- Login and Sign Up

- Profile
- Cooking 101
